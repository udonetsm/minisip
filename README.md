# MiniSIP

!ВНИМАНИЕ! Это приложение полностью сгенерировано нейросетью. Будьте внимательны с тем, что передаете через него. Приложение не проходило аудит безопасности и полноценное нагрузочное тестирование.

Минималистичный, производительный SIP-клиент и IKEv2/ESP VPN-клиент для Android.
Приложение написано полностью без сторонних библиотек: протоколы **SIP, SDP, Digest, RTP, G.711, IKEv2 и ESP** реализованы с нуля.

Нужны только стандартная платформа Android SDK 35 и Java 17.

---

## 🏗 Архитектура

Проект строго разделен на изолированные пакеты. Каждый пакет предоставляет один публичный интерфейс и статическую фабрику `create(...)`. Реализации скрыты внутри пакета (`package-private`).

```
ru.minisip
├── net     Udp      ← Чистые сетевые сокеты и привязка к сетям (Android ConnectivityManager)
├── media   Media    ← RTP, G.711 кодек, микрофон и динамик (AndroidAudio, AudioRecord, AudioTrack)
├── sip     Sip      ← Протокол SIP (REGISTER, INVITE, BYE, CANCEL, Digest-MD5, SDP)
├── screen  Screen   ← Управление экраном и датчиком приближения
├── vpn     Vpn      ← IKEv2/ESP VPN-клиент, tun-интерфейс, обработка пакетов
└── app              ← Корень композиции, логика сессий, многоаккаунтность и UI на Material 3
```

### Принципы архитектуры:
- **Отсутствие зацепления**: пакеты не зависят друг от друга напрямую, а общаются только через интерфейсы.
- **Встроенные типы на границах**: между пакетами ходят только базовые типы Java (`String`, `int`, `byte[]`, `boolean`) и интерфейсы-слушатели.
- **Проверка импортов**: скрипт `python3 tools/check_imports.py` автоматически валидирует правила слоев.

## 📱 Функциональность и возможности

### 1. Подключение к АТС (SIP)
- Регистрация на SIP-сервере с поддержкой авторизации **Digest-MD5**.
- Поддержка отправки `Expires: 0` при отключении для мгновенного снятия регистрации на сервере.
- **Индикаторы состояния со светофором**:
  - `🔴 Disconnected` — отключено / нет соединения.
  - `🟡 Connecting...` — идет процесс подключения/авторизации.
  - `🟢 Connected` — регистрация успешно выполнена.
  - `🔴 Error: ...` — ошибка подключения или авторизации.
- **Динамическая блокировка полей**: при активном подключении к АТС или во время вызова поля `Server`, `Login`, `Password` блокируются от случайного изменения.
- Защита от звонков при отсутствии соединения: если АТС не подключена, звонок не запускается и не расходует ресурсы.

### 2. Исходящие вызовы и Звуковой тракт
- **Только исходящая связь**: входящие звонки отсекаются с авто-ответом `486 Busy Here`.
- **Захват аудиоустройств**: использование `AudioRecord` (`VOICE_COMMUNICATION`) и `AudioTrack` с системным эхоподавлением и подавлением шумов.
- **Устойчивый старт аудио**: циклический прогрев звукового драйвера (до 5 попыток с интервалом 100 мс) гарантирует успешную инициализацию микрофона/динамика с первой попытки даже при пробуждении смартфона из глубокого сна.
- **Управление звуковым фокусом (Audio Focus)**: при старте звонка запрашивается эксклюзивный фокус `AUDIOFOCUS_GAIN_TRANSIENT_EXCLUSIVE`. Любое стороннее медиа (музыка, видео, плееры) автоматически ставится на паузу и возобновляется после завершения разговора.
- **Индикация статуса вызова**:
  - `🟡 Calling...` — идет дозвон.
  - `🟢 Call in progress` — собеседник поднял трубку, идет разговор.
  - `🔴 Ended: ...` — вызов завершен или отклонен.
- **Поддержка Early Media**: обработка ответа `183 Session Progress` / `180 Ringing` с SDP для проигрывания гудков от АТС с бесшовным переходом на разговор при ответе (`200 OK`).
- **Увеличенные элементы управления**: крупные цифры набора номера (`35 sp`) и крупная кнопка вызова (`22 sp`).
- **Переключение вывода**: мгновенное переключение на лету между разговорным динамиком (`Earpiece`) и громкой связью (`Speakerphone`).

### 3. IKEv2/ESP VPN-клиент
- **Режимы авторизации**:
  - Вход по логину и паролю (EAP-MSCHAPv2) с валидацией цепочек X.509 сертификатов (системное хранилище или пользовательский PEM CA).
  - Вход по общему ключу (PSK).
- **Двухуровневая структура настроек**:
  - Основной спойлер `VPN settings ▼` скрывает поля `VPN server`, `VPN login`, `VPN password` и кнопку `Apps using VPN`.
  - Вложенный спойлер `Advanced VPN settings ▼` скрывает второстепенные поля (`VPN pre-shared key`, `VPN CA certificate`, `Healthcheck address`).
- **Раздельное маркерное шифрование (Split Tunneling)**: выбор приложений (`Apps using VPN`), чей трафик направляется в туннель.
- **Привязка сокетов**: после подъема туннеля SIP- и RTP-сокеты привязываются строго к интерфейсу `tun0`.
- **Умный Healthcheck (по умолчанию `google.com`)**:
  - Поддержка ввода как IPv4-адреса, так и доменных имен в поле `Healthcheck address`. При вводе домена выполняется фоновое DNS-разрешение перед стартом VPN.
  - Отправка сырых ICMP Echo-запросов через ESP каждые 2 секунды.
  - Потеря фиксируется при **6 подряд неответных пакетах** (12 секунд тишины), что исключает ложные срабатывания на мобильных сетях.
  - Перед реконнектом выполняется проверка DPD (Dead Peer Detection).
  - Индикация статуса: `🔴 VPN: disconnected`, `🟡 VPN: connecting...`, `🟢 VPN: connected (tun0)`, `🟡 VPN: reconnecting (attempt N)`.
- **Корректная обработка вытеснения (Takeover)**: при запуске другого VPN-клиента в системе MiniSIP мгновенно завершает вызов, закрывает сокеты и отключает АТС без ухода в бесконечный цикл.

### 4. Датчик приближения (`Screen`)
- Экран гаснет при поднесении телефона к уху (`PROXIMITY_SCREEN_OFF_WAKE_LOCK`) и включается при отстранении.
- После завершения разговора экран остаётся погашенным до отстранения смартфона от лица.

### 5. Пользовательский интерфейс и Жесты (Material 3)
- Построен полностью на интерфейсных компонентах **Material 3** без использования XML-ресурсов разметки.
- **Интерфейс на английском языке**: все кнопки, подписи, диалоги и сообщения об ошибках приведены к стандарту на английском языке.
- **Перетаскивание карточек (Drag-and-Drop)**: зажмите любую из 3 карточек блоков (`SIP server settings`, `Number and voice source`, `VPN settings (IKEv2)`), чтобы перетащить ее и изменить порядок. Порядок сохраняется в настройках страницы.
- **Управление страницами (Многоаккаунтность)**:
  - Свайп вправо для создания новой карточки настроек запрашивает диалоговое подтверждение (`Create New Card`).
  - Проскролльте страницу до самого низа, потяните вверх в любом месте экрана и задержите на **1 секунду** — плавно появится красная кнопка `Delete Page 🗑` с автоскроллом и фокусом.
  - Нажатие на `Delete Page 🗑` открывает диалог подтверждения удаления. При единственной оставшейся странице удаление заблокировано.
- **Фирменная стилизация кнопок диалогов**:
  - Кнопка **`No`**: яркая синяя (`#2196F3`), выделенная жирным шрифтом.
  - Кнопка **`Yes`**: тускло-серая с 20% полупрозрачностью (`alpha = 0.80f`).

## 🧪 Тестирование без Android SDK

В папке `jvmtest/` подготовлены автономные JVM-тесты, не требующие запущенного эмулятора или Android SDK:

```bash
sh jvmtest/run.sh
```

### Проверяется автоматически:
- Архитектура импортов между пакетами (`check_imports.py`).
- Кодек G.711 и парсинг RTP.
- Авторизация SIP Digest-MD5 по RFC 2617.
- Привязка сокетов к сетевым интерфейсам (`NetTest`).
- Криптография и ESP: HMAC (RFC 4231), MD4 (RFC 1320), MS-CHAPv2 / MPPE (RFC 2759/3079), окно повторов (`CryptoTest`).
- Полный IKEv2-туннель против скриптового ответчика `jvmtest/fake_ike.py` (22 сценария: алгоритмы, cookie, ошибки ключей, DPD, разрыв связи, подделки сертификатов и т.д.).

## ⚠️ Текущие ограничения

- **Кодеки**: поддерживаются PCMA (G.711 a-law) и PCMU (G.711 u-law). DTMF, TLS/SRTP и перевод звонка отсутствуют.
- **VPN**: только IPv4 (маршрутизация IPv6 направляется в blackhole для отката приложений на IPv4).
- **Входящие звонки**: не поддерживаются (приложение ориентировано на исходящие вызовы).
