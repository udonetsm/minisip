# Подробное руководство пользователя MiniSIP

---

## 1. Введение и архитектурные особенности MiniSIP

**MiniSIP** — это высокопроизводительное Android-приложение, объединяющее в себе **клиент IP-телефонии (SIP/VoIP)** и **клиент шифрованного туннелирования (IKEv2/IPsec VPN)**.

Приложение спроектировано для работы в условиях нестабильных сетей и мобильной передачи данных:
- **Голосовые вызовы SIP**: Подключение к АТС (Asterisk, FreePBX, Kamailio, 3CX, Yate и др.) по протоколу RFC 3261.
- **Встроенный IKEv2/IPsec VPN**: Нативная реализация стека IKEv2/ESP на чистом Java/Android API без тяжелых внешних библиотек и без необходимости получения Root-прав.
- **Работа в фоне**: Использование системных Foreground-сервисов (`CallService` и `TunService`) предотвращает завершение процессов ОС Android при заблокированном экране или в режиме энергосбережения Doze Mode.

---

## 2. Системные разрешения и первоначальная настройка

При первом запуске и активировании функций MiniSIP запрашивает следующие системные разрешения:

1. **Запись аудио (`RECORD_AUDIO`)**: Необходимо для захвата звука с микрофона во время вызова.
2. **Уведомления (`POST_NOTIFICATIONS`)** *(Android 13+)*: Требуется для работы фоновых сервисов и отображения статуса вызова/VPN в шторке уведомлений.
3. **Оптимизация батареи (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`)**: Отключение ограничений энергосбережения предотвращает отключение SIP-сокета и VPN-туннеля системой.
4. **Согласие на VPN-соединение**: Нажатие кнопки `VPN connect` вызывает стандартный диалог Android `VpnService` для подтверждения создания виртуального интерфейса `tun0`.
5. **Установка неизвестных приложений (`REQUEST_INSTALL_PACKAGES`)**: Разрешение требуется для автоматического обновления приложения через встроенный `UpdateBar` с GitHub Releases.

## 3. Управление профилями и карточками (ViewPager2)

Интерфейс MiniSIP организован в виде ленты карточек-профилей. Каждая страница содержит независимый набор настроек SIP и VPN.

### 3.1 Динамическое создание новой карточки
1. Заполните обязательные поля текущего профиля: **Server** и **Login** в блоке SIP.
2. Смахните экран влево (переход на следующую страницу).
3. Появится диалоговое окно: *"Create New Card. Are you sure you want to create another settings card?"*.
4. Нажмите **Yes** — будет создана новая страница настроек с новым файлом конфигурации (`cfg1`, `cfg2` и т.д.).

### 3.2 Сортировка карточек (Drag & Drop)
1. Зажмите заголовок любого блока (SIP, Call, VPN) до снижения прозрачности карточки (`alpha = 0.2`).
2. Перетащите блок вверх или вниз.
3. Отпустите заголовок — новый порядок блоков сохраняется в настройках профиля под ключом `blockOrder`.

### 3.3 Удаление карточки
1. Прокрутите текущую страницу до самого низа и удерживайте натяжение вниз в течение 1 секунды.
2. Появится красная кнопка **Delete Page** (с иконкой ![Удалить](docs/icons/ic_delete.svg)).
3. Нажмите кнопку и подтвердите удаление в диалоговом окне. Страница будет удалена, а последующие профили автоматически сдвинутся влево с очисткой старых файлов `SharedPreferences`.

## 4. Подробное руководство по SIP-телефонии

### 4.1 Настройка параметров SIP-сервера
В блоке **SIP server settings** заполните:
- **Server**: IP-адрес или домен АТС (например, `192.168.1.100` или `sip.company.com:5060`). При указании порта через двоеточие порт парсится автоматически.
- **Login**: Ваш добавочный номер или логин SIP (например, `101`).
- **Password**: Пароль от аккаунта SIP.
- **Кнопка SIP settings**: Раскрывает дополнительные параметры настройки SIP с векторными индикаторами разворота (![Развернуть](docs/icons/ic_expand_more.svg) / ![Свернуть](docs/icons/ic_expand_less.svg)).

### 4.2 Подключение и статус
- **Connect**: Отправка запроса регистрации `REGISTER`.
- **Disconnect**: Отмена регистрации `REGISTER (Expires: 0)`.
- Индикация статуса:
  - **Disconnected**: Не подключено.
  - **Connecting...**: Выполняется регистрация и дайджест-авторизация (401/407 Challenge).
  - **Connected (Registered)**: Успешная регистрация на АТС.

### 4.3 Управление вызовами и разговорные опции
- **Number**: Поле набора номера увеличенного размера.
- **Call / Hangup**: Запуск вызова или завершение разговора с использованием иконок ![Вызов](docs/icons/ic_call.svg) и ![Отбой](docs/icons/ic_call_end.svg). При вызове статус сменяется на `Calling...`, а затем на `Talk`.
- **Mute**: Отключение микрофона с использованием иконок ![Микрофон](docs/icons/ic_mic.svg) / ![Без звука](docs/icons/ic_mic_off.svg). Нажатие переключает режим.
- **Spk**: Переключение вывода звука между громкой связью и разговорным динамиком (![Динамик](docs/icons/ic_volume_up.svg)).
- **Refers**: Окно перевода вызова.
  - Позволяет вести список сохраненных контактов (Login + Name).
  - Нажатие на иконку перевода (![Перевод](docs/icons/ic_transfer.svg)) напротив контакта выполняет **слепой перевод (Blind Transfer)** активного разговора по протоколу RFC 3515.
  - Нажатие на иконку удаления (![Закрыть](docs/icons/ic_close.svg)) удаляет контакт из списка.

### 4.4 Интерактивная графическая история звонков и цепочки статусов в номеронабирателе (Call History Status Chains)
MiniSIP содержит усовершенствованный журнал истории вызовов, в котором все события логирования автоматически группируются в хронологические сессии звонков с цветными цепочками статусов:
- **Логика группировки сессий**: Событие `dial` открывает новую сессию только в том случае, если предыдущий вызов уже завершился терминальным событием (`hangup`, `ended` или `error`). Если вызов продолжается, вся цепочка событий (`dial` -> `ringing` -> `connected` -> `hangup`) объединяется в единую сессию вызова.
- **Цветовые индикаторы состояний (Status Dots)**: Каждая фаза звонка отображается отдельным цветным круговым индикатором:
  - **Оранжевый (`#FF9800`)**: Дозвон (`dial`)
  - **Желтый/Золотой (`#FFD54F`)**: Гудки / Вызов (`ringing`)
  - **Зеленый (`#4CAF50`)**: Разговор / Соединение установлено (`connected`)
  - **Фиолетовый (`#9C27B0`)**: Перевод вызова (`transfer`)
  - **Красный (`#F44336`)**: Завершение / Сброс / Ошибка (`ended`, `error`, `hangup`)
- **Компактный стек статусов**: В заголовке каждой сессии отображается мини-превью из цветных точек, суммирующих ход вызова.
- **Разворачиваемая шкала времени (Timeline)**: Нажатие на заголовок сессии разворачивает или сворачивает детали с помощью векторных индикаторов (![Развернуть](docs/icons/ic_expand_more.svg) / ![Свернуть](docs/icons/ic_expand_less.svg)) для отображения детальной горизонтальной цепочки событий. Нажатие на любую точку статуса открывает диалог с полной информацией о событии и кнопкой **Copy**.
- **Быстрый набор (Quick Dialing)**: Долгое нажатие на заголовок сессии истории автоматически копирует и подставляет номер абонента в основное поле ввода **Number**.
- **Копирование сессии**: Кнопка копирования (![Копировать](docs/icons/ic_copy.svg)) позволяет скопировать всю сводку сессии вызова в буфер обмена.

## 5. Подробное руководство по встроенному VPN (IKEv2/IPsec)

### 5.1 Основные и расширенные параметры VPN
В блоке **VPN settings (IKEv2)** задействованы спойлеры:
- **VPN settings**:
  - **VPN server**: Адрес VPN-шлюза.
  - **VPN login**: Логин пользователя (EAP / MS-CHAPv2).
  - **VPN password**: Пароль пользователя.
  - **Apps using VPN**: Настройка раздельного туннелирования трафика.
- **Advanced VPN settings**:
  - **VPN pre-shared key**: Общий секретный ключ (PSK), если используется аутентификация по ключу.
  - **VPN CA certificate (PEM)**: Сертификат удостоверяющего центра для проверки шлюза.
  - **Healthcheck address**: Адрес эхо-запросов для контроля доступности (IP или домен). Если указан домен, MiniSIP выполнит фоновый резолв DNS перед подключением. Если поле пустое или в нем 0, то проверяется только доступность самого сервера, а не доступность конкретного узла через него.
  - **Ping interval (sec)**: Интервал контрольных проверок в секундах (от 5 до 9 секунд, либо 0 для значения по умолчанию 5 с).

### 5.2 Удален.

### 5.3 Выборочное туннелирование (Apps using VPN)
1. Нажмите **Apps using VPN**.
2. Из списка установленных приложений отметьте галочками программы, трафик которых должен идти через VPN.
3. Нажмите **OK**. Все неотмеченные приложения будут работать через прямое подключение.

## 6. Расширенные жесты, логирование и автообновления

### 6.1 Переключение каналов обновлений и жесты
- **Долгое нажатие на строку версии vX.Y.Z (1 секунду)**: Открывает окно выбора канала обновлений (**Stable** or **Pre-release**) с кнопкой мгновенной проверки **Check**.
- **Тумблер строки версии**: Открывает лог работы модуля обновлений (`updateLog`).
- **UpdateBar**: При обнаружении нового релиза на GitHub внизу экрана появляется плашка с прогресс-баром скачивания и кнопкой установки.

### 6.2 Работа с консолями логов (LogArea)
В каждом блоке доступна независимая консоль логов (**SIP Log**, **VPN Log**, **Call Log**, **Update Log**):
- **Enable / Disable**: Включение и отключение вывода логов в реальном времени.
- **▲ / ▼**: Векторные стрелки прокрутки (![Свернуть](docs/icons/ic_expand_less.svg) / ![Развернуть](docs/icons/ic_expand_more.svg)).
- **Save**: Сохранение текста лога в файл через диалог (![Сохранить](docs/icons/ic_save.svg)).
- **Clear**: Полная очистка текущего буфера логов (![Удалить](docs/icons/ic_delete.svg)).

## 8. Справочник: кнопки, жесты и события

Эта глава — единая шпаргалка по всем интерактивным элементам интерфейса MiniSIP. Отвечает на вопрос: *«что произойдёт, если нажать / удержать / свайпнуть именно это?»*

### 8.1 Блок SIP

| Действие | Что происходит |
|----------|----------------|
| Ввод в **Server** | Автосохраняется в настройки страницы. Формат `host` или `host:port`; порт по умолчанию `5060`. |
| Ввод в **Login** / **Password** | Автосохраняется. В **Password** есть кнопка-глаз для показа пароля. |
| Тап по **SIP settings** | Раскрывает/скрывает `Server`, `Login`, `Password`. Иконка-стрелка меняется. |
| Тап по **Connect** | Проверяет `Server` и `Login`, отправляет `REGISTER`. Неактивна, если сессией владеет другая страница или идёт звонок. |
| Тап по **Disconnect** | Отправляет `REGISTER (Expires: 0)`. Активна только при активной регистрации/подключении. |
| Тап по **Refers** | Открывает редактор контактов blind transfer. |
| Переключатель **Log** (SIP) | Включает живой лог SIP-сигнализации. |
| Иконка сохранения (SIP) | Диалог: копировать в буфер или сохранить в `Documents/MiniSIP/logs`. |
| Иконка очистки (SIP) | Подтверждение → очистка буфера SIP-лога. |
| **▲ / ▼** (SIP) | Прокрутка лога в начало / конец. |

### 8.2 Блок Dialer

| Действие | Что происходит |
|----------|----------------|
| Ввод в **Number** | Размер шрифта автоматически уменьшается с 24sp до 10sp, чтобы влезть в поле. |
| **Долгое нажатие на Number (1 с)** | Очищает поле. |
| Тап по **Call / Hangup** | В покое: совершает звонок (проверка разрешения на микрофон, применение ваших настроек `Spk` / `Mute`). Во время звонка: сбрасывает. Иконка становится красной, когда звонок активен. |
| Тап по **Mute** | Переключает микрофон. При выключенном микрофоне — прямоугольник с закругленными краями. Меняется цвет. При включенном микрофоне - эллипс |
| Тап по **Spk** | Переключает громкую связь ⇄ разговорный динамик. Громкая связь включена - кнопка прямоугольная со скругленными краями. Меняется цвет. Громкая связь  выключена - эллипс |
| Тап по **заголовку сессии** в истории | Разворачивает/сворачивает горизонтальную шкалу статус-дотов. |
| **Долгое нажатие на заголовок сессии** | Копирует номер этой сессии в поле **Number** и показывает Toast «Number inserted». |
| Тап по **точке статуса** | Диалог с полным текстом события и кнопками **Copy** / **Close**. |
| Тап по **иконке копирования** рядом с сессией | Копирует всю сессию (номер + все события) в буфер обмена. |
| **▲ / ▼** под историей | Плавная прокрутка списка. |
| Иконка сохранения под историей | Копировать или сохранить историю звонков. |
| Иконка очистки под историей | Подтверждение → очистка журнала. |

### 8.3 Блок VPN

| Действие | Что происходит |
|----------|----------------|
| Тап по **VPN settings** | Раскрывает/скрывает основные поля + **Apps using VPN** и **Advanced VPN settings**. |
| Тап по **Advanced VPN settings** | Раскрывает/скрывает PSK, CA-сертификат, healthcheck, ping interval. |
| Ввод в **VPN pre-shared key** | Опциональный PSK. Оставьте пустым, чтобы использовать EAP / MS-CHAPv2. |
| Ввод в **VPN CA certificate** | Опциональный PEM-bundle. Пусто → системное trust-store. |
| Ввод в **Healthcheck address** | IP или hostname. Пусто или `0` → проверка самого VPN-сервера. Домены резолвятся в IPv4 в фоне перед подключением. |
| Ввод в **Ping interval (sec)** | Допустимо 5..9 или `0` (по умолчанию 5). Неверные значения прерывают подключение. |
| Тап по **Apps using VPN** | Открывает picker split-tunneling. Подпись — `MiniSIP + N`, где N — число выбранных приложений. |
| Тап по **VPN connect** | Проверяет поля, запрашивает согласие VPN при необходимости, подключается. При активном подключении подпись показывает `MOBIKE:` и состояние `DPD:`. |
| Тап по **VPN disconnect** | Разрывает туннель. |
| Переключатель **Log** / save / clear / **▲ / ▼** (VPN) | То же, что в SIP-блоке, но для `vpnLog`. |

### 8.4 Карточки и жесты уровня приложения

| Жест | Что происходит |
|------|----------------|
| **Долгое нажатие на метку версии `vX.Y.Z` (2 с)** | Открывает выбор канала (Stable / Pre-release) с кнопкой **Check**. |
| **Сдвиг пальца более чем на 20 dp** во время этого удержания | Отменяет диалог канала. |
| **Натяжение вниз в самом низу scroll-view в течение 1 с** | Проявляет красную кнопку **Delete Page** (только если страниц больше одной). |
| **Долгое нажатие на заголовок карточки (SIP / Call / VPN)** | Перетаскивание карточки для смены порядка. Порядок сохраняется в настройках страницы. |
| **Свайп на следующую страницу**, когда текущая уже сконфигурирована | Открывает диалог **Create New Card**. |
| **Плитка Quick Settings** | Переключает VPN без открытия приложения. Долгое нажатие открывает выбор профиля (если их несколько). |
| Первый запуск | Система спрашивает `RECORD_AUDIO`, `POST_NOTIFICATIONS`, исключение из оптимизации батареи и (один раз) предлагает добавить плитку MiniSIP VPN в Quick Settings. |
