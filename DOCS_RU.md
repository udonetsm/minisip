# 📱 MiniSIP — Руководство пользователя

**MiniSIP** — это лёгкое и удобное приложение для Android, предназначенное для безопасных голосовых звонков через интернет (SIP-телефония) и работы через защищённый VPN-туннель (IKEv2/IPsec).

Приложение не содержит лишних сервисов, не расходует лишний заряд батареи и позволяет настроить работу с вашей АТС за считанные секунды.

## 1. Основные возможности

- **SIP-телефония**: Подключение к корпоративным и публичным АТС (Asterisk, FreePBX, 3CX и др.) с поддержкой кодека G.711 (PCMA/PCMU).
- **Встроенный IKEv2 VPN**: Безопасный туннель с поддержкой паролей, секретных ключей (PSK), сертификатов и автоматического восстановления связи.
- **Маршрутизация приложений**: Возможность выборочно направлять трафик других приложений через VPN.
- **Слепой перевод вызова (Blind Transfer)**: Быстрый перевод активного звонка на другой номер из книги контактов (Refers).
- **Поддержка нескольких профилей**: Создание нескольких независимых страниц настроек с удобным переключением.
- **Интерактивные блоки**: Изменение порядка блоков настроек простым перетаскиванием (Drag-and-Drop).

## 2. Настройка SIP-телефонии

Для подключения к вашей АТС найдите блок **«SIP server settings»**:

1. Нажмите на кнопку **«SIP settings ▼»**, чтобы открыть поля ввода.
2. Заполните данные вашей учетной записи:
   - **Server**: IP-адрес или доменное имя АТС (например, `192.168.1.100` или `pbx.example.org`). Если АТС использует нестандартный порт, укажите его через двоеточие: `pbx.example.org:5060`.
   - **Login**: Ваш внутренний номер или логин (например, `101`).
   - **Password**: Пароль от SIP-аккаунта.
3. Нажмите кнопку **«Connect»**.
4. Проверьте строку статуса:
   - 🟡 **Connecting...** — выполняется подключение к серверу.
   - 🟢 **Connected** — подключение успешно установлено, вы готовы совершать звонки.
   - 🔴 **Error...** — ошибка подключения (проверьте логин, пароль и адрес сервера).

Для отключения от АТС нажмите кнопку **«Disconnect»**.

## 3. Совершение и управление звонками

Блок **«Number and voice source»** предназначен для набора номера и управления голосовым трактом:

### Совершение вызова:
1. Введите номер абонента в крупное поле ввода **«Number»**.
2. Нажмите синюю кнопку **«📞»**.
3. При первом звонке приложение запросит разрешение на доступ к микрофону — подтвердите его.
4. В процессе звонка статус изменится на 🟢 **Call in progress**.
5. Для завершения разговора нажмите красную кнопку **«🚫»**.

### Управление звуком во время разговора:
- **📢 Speaker / 👂 Earpiece**: Переключение между разговорным динамиком (в ухо) и громкой связью. Активный источник подсвечивается зелёной рамкой.
- **🤫 Mute mic / 👄 Unmute mic**: Отключение и повторное включение микрофона.

## 4. Перевод вызова (Refers)

Функция **Refers** позволяет быстро перевести текущий разговор на другой внутренний номер без предварительного звонка (слепой перевод).

### Настройка списка контактов перевода:
1. В блоке SIP нажмите кнопку **«Refers»**.
2. В открывшемся окне нажмите **«Add»**, чтобы добавить новый контакт.
3. Укажите **Login** (номер абонента) и **Name** (имя для удобства).
4. Все изменения сохраняются автоматически.

### Перевод активного звонка:
1. Во время разговора нажмите кнопку **«Refers»**.
2. Найдите нужного абонента и нажмите иконку перевода **↪️**.
3. Подтвердите действие в появившемся запросе.
4. Вызов будет мгновенно переведён на выбранный номер.

## 5. Подключение и настройка VPN (IKEv2)

Блок **«VPN settings (IKEv2)»** обеспечивает защищённое соединение с вашим VPN-сервером.

### Основные настройки:
1. Нажмите кнопку **«VPN settings ▼»**.
2. Укажите параметры подключения:
   - **VPN server**: Адрес или IP VPN-сервера.
   - **VPN login**: Ваш VPN-логин (например, `user@example.org`).
   - **VPN password**: Пароль от VPN.
3. Нажмите кнопку **«VPN connect»**. При первом запуске Android попросит подтвердить разрешение на создание VPN-подключения.

### Расширенные настройки VPN:
Нажмите кнопку **«Advanced VPN settings ▼»** для доступа к дополнительным опциям:
- **VPN pre-shared key**: Общий секретный ключ (PSK), если сервер использует его вместо пары логин/пароль.
- **VPN CA certificate (PEM)**: Сертификат удостоверяющего центра в формате PEM (если требуется для проверки сервера).
- **Healthcheck address**: IP-адрес или домен для проверки доступности сети через VPN.
- **Apps using VPN**: Выбор приложений на телефоне, трафик которых должен идти через VPN-туннель.

### Строка статуса и индикаторы VPN:
- 🟢 **VPN: connected (tun0)** — соединение установлено и активно.
- 🟡 **VPN: reconnecting...** — автоматическое переподключение при смене сети.
- В строке статуса также отображаются параметры:
  - **Loss**: количество потерянных пакетов проверки связи.
  - **Recon**: количество выполнившихся переподключений.
  - **MOBIKE**: статус поддержки миграции между Wi-Fi и мобильной сетью без обрыва туннеля.
  - **DPD**: состояние проверки активности сервера.

## 6. Управление карточками и профилями

### Настройка нескольких профилей (страниц):
- Вы можете создать несколько страниц настроек (например, «Офис», «Дом», «Командировка»).
- Переключение между страницами осуществляется свайпом влево или вправо.
- Чтобы добавить или удалить страницу, прокрутите экран вниз до самого конца и зажмите кнопку **«Delete Page 🗑»**.

### Изменение порядка блоков (Drag-and-Drop):
- Порядок блоков («SIP server settings», «Number and voice source», «VPN settings») можно изменять.
- Зажмите любую карточку пальцем на 1 секунду и перетащите её выше или ниже. Порядок сохраняется автоматически.

## 7. Просмотр и сохранение логов

Каждый блок приложения содержит встроенный журнал событий (Log) для диагностики работы:

1. Нажмите на троеточие **⋮** в правом верхнем углу любого блока и выберите **«Log»**.
2. В появившейся панели нажмите кнопку **«Enable»**, чтобы включить отображение логов.
3. Доступные действия с логами:
   - **Clear** — очистить текущий журнал.
   - **Copy** — скопировать весь текст лога в буфер обмена.
   - **Save** — сохранить журнал в текстовый файл в папку `Downloads/MiniSIP/logs`.

## 8. Обновление приложения

В самом низу экрана отображается текущая версия приложения (например, `v1.0.0`).

### Настройка канала обновлений:
1. Зажмите строку с версией приложения на 2 секунды.
2. В появившемся окне выберите канал обновлений:
   - **Stable** — только проверенные стабильные релизы.
   - **Pre-release** — предварительные версии с новыми функциями.
3. Нажмите **«Check»** для проверки наличия обновлений.

При наличии новой версии вверху экрана появится плашка скачивания с индикатором прогресса и кнопкой **«Install»**.
